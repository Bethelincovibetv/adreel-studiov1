# AdReel Studio

A modern React application for creating animated advertising video reels, vertical video storyboards, whiteboard explainer sketches, and 3D cinematic human explainer scenes.

## Features

- **AdReel Script Engine**: Paste any advertising script to parse brand, offers, guarantees, benefits, and call-to-action beats into timed animated scenes.
- **Graphic Templates**: 11 visual themes including Bold Business Promo, Premium Luxury, Big Sale / Discount, Neon Tech, Food & Restaurant, Beauty & Fashion, Gospel & Church Event, Corporate Clean, Real Estate, Whiteboard Explainer, and Human Presenter Explainer.
- **Interactive 9:16 Canvas**: Smooth real-time preview of high-resolution vertical video animations with hero illustrations, character bobbing, animations, and transitions.
- **Whiteboard Sketch Mode**: Edge-detection filter with hand-drawing animation and custom story frameworks (Problem-Solution, How-To, Product Explainer, Testimonial, etc.).
- **Real-Time Video Recording & Web Audio Synthesizer**: Record videos in-browser with procedural chords, bassline, transition swooshes, and sound effects using MediaRecorder (MP4 / WebM export).
- **Google Real-Human Explainer Studio**: Generate detailed prompt frameworks for realistic video generation models.
- **3D Cinematic Human Studio**: Multi-character, multi-environment (office, shop, studio, street, stage, home) explainer scene simulator with customizable lighting effects and PNG export.
- **Editable Storyboard JSON**: Direct live two-way editing between storyboard code and visual animation.

## Getting Started

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```
